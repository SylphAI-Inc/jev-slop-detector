What Jev returns

State plus typed questions in. Typed answers with probabilities out. Not a paragraph.

In

state: "Tried Stripe for 3 days.
Losing sales. Help ASAP."

questions:
  department  choice
    billing | technical | sales
  frustration  score
    0 calm
    1 frustrated but civil
    2 very angry
  is_urgent  noul

department    technical  0.85
frustration   1  frustrated but civil
is_urgent     1.0

Your code branches. 70–500 ms. No text to parse.

Loop engineering: work until the goal is achieved

  1. 1

    Premature stop

    The model says it will run the tests, and never calls the tool. About 10% of tool calls stop like this. Jev catches that, we bounce, and the same turn continues. This one is shipped, so you will not see it in AdaL now.

  2. 2

    Auto permission

    Before a destructive command, Jev can allow it, ask you, or deny it. That is a more secure YOLO. Not shipped yet.

  3. 3

    Goal achieved

    When the model tries to stop, is the finish line actually crossed? If not, another turn starts. That is /goal, and it is next.
